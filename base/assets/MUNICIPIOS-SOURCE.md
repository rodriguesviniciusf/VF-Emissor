# Catálogo offline de municípios

Fonte: IBGE, Divisão Territorial Brasileira 2025, data base 31/12/2025.
Arquivo público: https://geoftp.ibge.gov.br/organizacao_do_territorio/estrutura_territorial/divisao_territorial/2025/DTB_2025.zip

Preservados código completo, nome e UF da tabela oficial de municípios, incluindo Fernando de Noronha. Origem, data de obtenção e SHA-256 do ZIP constam em municipios.json. Sem dados pessoais. Atualização reproduzível: python scripts/refresh_municipalities.py.
